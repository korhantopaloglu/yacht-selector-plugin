Short description of the Yacht Selector plugin.

== Description ==

Yacht Selector is a custom plugin that renders a yacht selection interface using a shortcode.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/yacht-selector/` directory.
2. Activate the plugin through the 'Plugins' screen in WordPress.
